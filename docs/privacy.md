# BriefDeck 隐私说明

BriefDeck 根据用户主动提交的主题、材料和要求生成演示内容。

- Anna 模式：AI 请求通过 Anna 平台处理，项目通过 Anna 自身 app scope 的 APS 保存。模型和额度遵循用户的平台配置。
- 本地预览：示例及手动编辑的项目保存在当前浏览器 localStorage，不调用模型。
- AI 输入包含当前任务所需的主题、受众、目标、材料及页面内容；单页改写还包含相邻结构摘要。
- 用量记录保存操作、模型、token、CU、时间和结果状态，不保存材料正文。平台账单为费用最终依据。
- PPTX 导出文件保存在用户自身 app scope；删除项目时一并请求删除导出文件。
- 项目默认不对其他用户公开，不发送到独立开发者服务器。
- 应用不包含第三方广告或分析 SDK，不请求摄像头、麦克风和本地系统权限。
- 用户可以在项目库下载 JSON 备份或删除项目。卸载浏览器或清除网站数据会影响本地预览项目。

业务数字、个人资料或敏感材料提交前，请确认拥有相应处理权限。正式使用前请检查 AI 内容与原始材料是否相符。
