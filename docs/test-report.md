## 真实测试发现与修复

- 核心结论页出现四条正文：自动转换为列表，保留全部内容；手动使用该版式时限制文本框在画布内。
- 英文大纲重复内部 ID：新大纲 ID 改由应用按顺序分配，原有标题和内容完整保留。
- JSON 输出可能有格式错误：每次最多一次修复，操作总计最多两次，逐次计入用量。
- 同窗口自动保存与生成保存可能重叠：Repository 层串行化，跨窗口使用 etag。
- SDK 打包引发麦克风静态误报：按官方方式动态加载宿主 SDK，不添加不需要的权限。
- CLI 参数与部分文档不一致：依据锁定 CLI 的 help 使用受支持参数。
- 中文字体回退：QA 配置独立 Fontconfig 指向系统字体，保持 PPT 文字可编辑。
